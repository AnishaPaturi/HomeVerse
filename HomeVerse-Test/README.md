# HomeVerse Procedural Dataset (Diverse Geometry)

Geometry-first synthetic dataset with 10k+ diverse architectural typologies.

## Typologies Included:
- Rectilinear partitioned layouts (studios, apartments, residences)
- L-shaped winged residences with corner patios
- T-shaped modular residences with central stem wings
- U-shaped courtyard layouts
- Staggered / Z-shaped articulated volume layouts
- Central corridor spine residential plans
- Non-convex L-shaped room carvings (open living/dining, ensuite baths)

## Scale Mode Distribution:
- 35.2% dimensioned (explicit room dimension text)
- 30.8% scale-bar (graphical distance scale bar)
- 22.0% reference-object (architectural fixtures with metric scale tags)
- 12.0% no-scale (raw geometry only, unannotated)

## Split Integrity:
Split strictly by unique layout ID. All 3 visual variants of any layout share the exact same split.

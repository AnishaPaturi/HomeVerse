# Mobile vs. Web Client Capabilities

HomeVerse delivers a complementary experience across web and mobile surfaces without replicating heavyweight desktop operations on mobile form factors.

## Responsibility Matrix

| Feature / Capability | Frontend-Web (Next.js) | Mobile App (Flutter) | Backend Enforcement |
|:---|:---:|:---:|:---:|
| **Public Landing Page & Showcase** | Full Interactive 3D Showcase | Lightweight Splash | FastAPI Static Serving |
| **Authentication & Profile** | Email + Password, Google OAuth | Email + Password, Google OAuth | Central JWT Tokens |
| **Turnkey Home Creation Wizard** | Full 9-Step Desktop Wizard | Full 9-Step Responsive Wizard | Validation & Budget DB |
| **Blueprint & CAD File Upload** | Drag & Drop PDF / PNG / DWG | Camera Capture & Gallery Picker | S3 / Local Storage |
| **Precision 2D Blueprint Editor** | Canvas Pan, Zoom, Wall Splitting | Read-Only Dimension Confirmation | OpenCV / YOLO |
| **3D Interactive Studio** | Full R3F Viewport & Gizmo Transforms | 3D Asset Preview & Property Tuning | Synchronized Scene Graph |
| **AI Copilot Voice & Chat** | Audio WebSpeech + Floating Drawer | Mobile BottomSheet Copilot | Central Agent Orchestrator |
| **Turnkey Budget & What-If Delta** | Detailed Spreadsheet & Allocations | Responsive Dashboard Cards | Real-Time Delta Engine |
| **Procurement & Shopping** | Full Table with Vendor Links | Mobile Card-Based Cart / Status | Unified Product Catalog |
| **House Walkthrough** | First-Person PointerLock Controls | Interactive Panoramic Floor Hop | Unified Spatial Nav Graph |

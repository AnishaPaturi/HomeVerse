# HomeVerse Product User Flow

## 1. End-to-End User Journey
HomeVerse guides homeowners from initial intent to actionable procurement through 9 structured steps:

```mermaid
flowchart TD
    Step1["1. Home Type Selection<br/>(Apartment, Villa, Studio, etc.)"] --> Step2["2. Floor Count Configuration<br/>(1, 2, 3, 4+ Levels)"]
    Step2 --> Step3["3. Room Count & Types<br/>(Living, Kitchen, Bedrooms, etc.)"]
    Step3 --> Step4["4. 💰 Target Budget & Flexibility<br/>(Presets ₹5L - ₹1Cr+, Strict/Moderate/Flexible)"]
    Step4 --> Step5["5. Floor Plan Upload<br/>(PNG, JPG, PDF, CAD)"]
    Step5 --> Step6["6. Dimension Confirmation & Tuning<br/>(Width, Length, Ceiling Height)"]
    Step6 --> Step7["7. Room Focus Selection<br/>(Prioritized Room Generation)"]
    Step7 --> Step8["8. Design Style DNA<br/>(Japandi, Modern, Scandinavian, Luxury, etc.)"]
    Step8 --> Step9["9. AI 3D Twin Synthesis<br/>(Atomic Project Creation)"]
    Step9 --> Workspace["Project Workspace<br/>(3D Playground, Walkthrough, Budget, Shopping)"]
```

## 2. In-Studio Experience
Once inside the workspace:
1. **Interactive 3D Playground**: Move furniture, test clearances, and converse with the AI Copilot.
2. **Budget Delta Alerts**: Modifying an item displays instant cost impacts (e.g. `+₹35,000`) and suggests value-engineering alternatives.
3. **Whole-House Walkthrough**: Switch between floor levels and inspect spatial connections in first-person mode.
4. **Itemized Procurement**: Review the bill of materials, swap products, and click direct vendor purchase links.

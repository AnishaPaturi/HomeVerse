# AI Workspace

This directory houses the AI research, experiments, datasets, and fine-tuned model artifacts for HomeVerse.

- `notebooks/`: Jupyter exploratory notebooks for vision, floor plans, and layout optimization
- `datasets/`: Dataset annotations, reference style dictionaries, and prompt pairs
- `experiments/`: Experiment tracking, metrics, and trial configurations
- `models/`: Weights, checkpoints, and serialized model pipelines
